# Snake game

Desktop Snake game written in Python Turtle. Eat food to grow and score; hitting the wall or body ends the game.

## Run locally

Use Python 3 with Tk/Turtle support and a desktop display. From the repository directory:

```bash
python main.py
```

No third-party Python packages are imported by this example. Use the arrow keys to steer. Click the game window after game over to close it. `main.py` runs the loop; `snake.py`, `food.py` and `scoreboard.py` define movement, food and scoring.
